# 藍髮小女僕桌寵

Windows-only 的獨立 Electron 桌寵基礎框架。此目錄不依賴 DSH，動畫素材目前直接取自上層專案已有的藍髮女僕 WebM，沒有生成新素材。

## 開發

```powershell
cd desktop-app
npm.cmd install
npm.cmd test
npm.cmd start
```

要直接使用免安裝版本，雙擊 `release-0.5.10/blue-maid-desktop-pet-0.5.10.exe` 即可，不需要安裝 Node.js、不會開啟瀏覽器。首次啟動需要先解壓縮執行環境，稍候會在主螢幕右下方出現桌寵。

更新前請先從舊版系統匣選「結束程式」（0.1.1 可右鍵桌寵退出）。新版重複啟動會開啟既有程式的設定視窗，不會啟動第二套管理程序。

目前版本提供：

- 透明、無邊框小視窗；可在設定中逐隻切換「永遠置頂」
- 系統匣女僕圖示：左鍵開啟設定，右鍵逐隻管理／全部顯示／全部隱藏；桌寵不佔一般工作列視窗按鈕。
- 隱藏／顯示與結束程式；關閉桌寵視窗只隱藏，不退出。隱藏期間暫停動畫與漫遊。
- 點按隨機觸發五種回應；移動超過 5 像素才視為拖曳，拖曳中循環懸空動畫，放開回待機。
- 轉向、專案素材中的三種行走動畫與自動漫遊；可設定每隻桌寵在所在螢幕工作區的左右漫遊範圍。
- 右鍵桌寵或系統匣圖示，可選「基本互動、移動、小動作、玩耍、吃東西、節慶、文字」。
- 動畫依上游分類權重隨機播放，文字類避免鏡像文字；關閉「自動漫遊」後仍可手動選擇移動動作。
- 設定介面支援每隻桌寵的大小（50–200%）、全域座標、所在螢幕、角落／中央定位、顯示、永遠置頂、自動漫遊及左右漫遊範圍。
- 可以新增／移除／複製桌寵；複製時可選擇是否一併複製對話與日記，副本之後完全獨立。
- 右鍵選「聊天」會在桌寵頭上開啟透明聊天泡泡，而非瀏覽器頁面。可在設定選擇 Gemini、OpenAI、DeepSeek 或自訂相容服務；金鑰由 Windows 的系統加密空間保存，桌寵泡泡不會取得金鑰。Gemini 與 OpenAI 的聯網回答會顯示可引用來源；未支援的服務不會改用瀏覽器或其他服務。
- 聊天可附加或貼上使用者明確選取的 PNG、JPEG、WebP 圖片（最多 3 張、單張 5 MiB、合計 10 MiB）；送出前可預覽與移除。僅目前有圖片輸入介面的服務會收到圖片，其他服務會在送出前拒絕，不會改用替代服務或讀取螢幕／任意檔案。
- 每隻桌寵可個別選擇記憶策略、自動寫日記、立即整理、查看獨立日記視窗、編輯／刪除日記或清除全部對話與日記。不保存模式會在確認後立即移除該桌寵的本機記錄；圖片附件隨原文保存及刪除，複製對話與日記不會複製附件檔案。
- 可編輯最後一則已送出的使用者訊息：會取消舊請求、移除舊回答及依賴它的日記，再產生新回答；已經播放的桌寵動作不能回復。
- 透明區域依當前影片的 alpha 遮罩讓滑鼠穿透；只有可見角色像素接收互動。按住角色拖曳期間保留滑鼠擷取。
- 拖曳改用 Windows 桌面 DIP 座標，不在螢幕接縫限制視窗；支援負座標螢幕。螢幕移除後會把失聯位置帶回可見區。

Windows 決定圖示是在通知區直接顯示或收入「^ 隱藏的圖示」。若想收起，可將女僕圖示拖入「^」區；程式不修改 Windows 通知區偏好或登錄檔。

## 設定儲存

大小、螢幕、顯示、置頂及漫遊變更後自動儲存；X／Y 與漫遊範圍分別按「套用位置」及「套用範圍」儲存。漫遊範圍使用所在螢幕工作區的 0–100% 左右界；座標是視窗左上角的全域邏輯像素，不是螢幕實體像素；左側或上方螢幕可使用負值。

桌寵使用隱藏的靜音影片作為動畫來源，將每幀繪製到透明 Canvas 顯示；顯示 Canvas 依桌寵大小以 640×360 為基準等比例調整，透明度命中則使用獨立的 320×180 遮罩畫布。這避免可見 HTML5 影片持續觸發 Windows 顯示喚醒要求，讓系統仍可依電源設定進入休眠。

正式版設定檔為 `%APPDATA%/blue-maid-desktop-pet/settings.json`，開發版為 `.runtime/settings.json`。拖曳結束、漫遊結束及正常退出均會保存位置；不支援強制終止程序時保證保存最後一刻的位置。設定檔損壞會明確報錯並停止啟動，不會靜默覆寫。設定視窗的座標草稿不會被背景漫遊更新覆蓋。

### 對話與日記資料

每隻桌寵的對話與日記分別保存在 userData 的 `memory` 目錄；圖片附件只保存於同一 userData 下由程式管理的私有附件目錄，記憶關閉時僅在程式執行期間暫存。預設「保留日記，原對話 30 天後清理」；另有永久保留、只保留日記與不保存四種模式。日記、原文與附件刪除只保證程式不再讀取或送出本機資料，不能撤回先前已傳給 API 服務商的內容，也不是磁碟安全抹除。

## 動畫與打包

共收錄 91 段原專案 WebM（包含 1 段拖曳專用動畫）；90 段可由選單手動選取。選單分類使用繁體中文，個別動作保留上游名稱。沒有生成新素材，來源與限制見 `ASSET-NOTICE.md`。

```powershell
npm.cmd run prepare:assets # 從上層專案複製既有素材與分類，不生成媒體
npm.cmd test               # 邏輯、IPC、設定與來源雜湊測試；GUI 測試預設略過
npm.cmd run test:desktop   # 在真正 Electron/Chromium 驗證設定 UI 行為
npm.cmd run dist           # 產出 Windows x64 portable EXE
```

`diagnostics/controls.cjs` 用獨立暫存設定驗證多桌寵、重啟還原、真實影片遮罩與跨螢幕游標追蹤；此開發診斷需另有 Playwright 執行環境。`diagnostics/interactions.cjs` 為舊 0.2.0 架構的歷史診斷，不適用於新版多桌寵管理。

不包含 DSH 帳戶／餘額事件、AI 碎碎念，也尚未移植上游的拋擲重力與碰撞物理。0.1.1 的透明空白視窗修正仍保留。
