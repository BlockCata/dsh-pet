# 系統匣與既有互動動畫

## 範圍

沿用 Windows 獨立 Electron 桌寵，加入系統匣與原專案適用的互動動畫。只使用既有素材；不改原 DSH 插件、不加網路服務或 AI 功能、不生成素材。

## 執行與驗證

1. 讀取上游動畫分類，匯入 91 段原始影片與現有圖示 → 逐一比對 SHA-256。
2. 系統匣與桌寵共用分類選單，支援顯示／隱藏、漫遊開關、退出 → Node 選單測試及真實 Tray/Menu/BrowserWindow 整合測試。
3. 點擊、懸空拖曳、轉向、影片同步移動、分類隨機鏈 → 純邏輯與 renderer 事件測試，真實影片解碼與視窗位置檢查。
4. 打包獨立 portable 0.2.0 → 檢查封裝內素材與啟動後實際播放，舊版檔案保留。

## 限制

- 「隱藏的圖示」折疊位置由 Windows 與使用者偏好決定，不修改登錄檔強制隱藏。
- 指標注入測試不是實體滑鼠長按；移動原生視窗後可能發生 lostpointercapture。測試驗證拖曳選片與取消復原，實體手動拖曳手感仍須使用者試用。
- 不加入原專案的拋擲物理、DSH 餘額或 AI 碎碎念事件。
